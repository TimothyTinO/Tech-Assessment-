# Neighbour Sum Generator

Create a program that processes a list of numbers
and calculates sums using neighbouring elements.

REMINDER: Write your own tests!

## ⚠️ Note
There is likely too much work to complete in the time given.

## Background
A data-processing system receives a sequence of measurements.

## Step 1: Add Adjacent Numbers
Calculate the sum of every adjacent pair.

## Step 2: Circular Neighbours
Include the sum of the last and first numbers.

## Step 3: Configurable Neighbour Distance
Allow a custom distance between neighbours.
