# Python Technical Assessment — Coding Problems

This folder contains a growing collection of Python coding challenges designed to strengthen programming fundamentals, develop problem-solving skills and prepare for technical assessments.

The challenges follow a similar structure to the Sigma Labs coding problems, including the Mexican Wave Generator and Pyramid Builder.

Each challenge introduces different programming concepts and gradually increases in difficulty, allowing us to build confidence before tackling more complex problems.

## Learning Objectives

Through these challenges, we aim to develop a stronger understanding of:

- **String Manipulation:** Indexing, slicing, splitting, replacing and searching.
- **Loops and Conditionals:** `for`, `while`, `enumerate()`, nested loops and conditional statements.
- **Data Structures:** Lists, tuples, dictionaries and their applications.
- **Sorting and Searching:** Organising data, finding patterns and handling multiple conditions.
- **Problem Solving:** Breaking down requirements, planning solutions and identifying edge cases.
- **Testing:** Writing automated tests using `pytest` to verify functionality.
- **Code Quality:** Writing readable, maintainable and reusable Python code.

As more challenges are added, additional programming concepts and techniques will be introduced.

## ⚠️ Important Information

Some challenges may contain more work than can reasonably be completed in a single sitting.

You are **not expected to complete every step immediately**.

The focus should be on understanding the requirements, developing a working solution and learning from the process rather than simply completing as many challenges as possible.

## How the Challenges Work

Each challenge is divided into progressive steps, starting with a straightforward implementation before introducing more complicated requirements.

Typically, the challenges follow this structure:

1. **Basic Implementation:** Develop a solution that meets the initial requirements.
2. **Additional Requirements:** Extend the existing functionality.
3. **Increased Complexity:** Introduce more challenging scenarios and edge cases.
4. **Advanced Extensions:** Combine concepts or implement more complex behaviour.

The number of steps may vary depending on the challenge.

Unless explicitly stated otherwise, new functionality should build on the previous steps.

## Testing Requirements

**REMINDER:** The examples provided in each challenge are a minimal starting point. You should be writing your own tests to ensure your code works as expected!

For each challenge:

- Write your own automated tests using `pytest`.
- Test normal inputs, boundary conditions and edge cases.
- Identify additional test scenarios beyond the provided examples.
- Ensure existing functionality continues to work when introducing new requirements.
- Refactor code where necessary to improve readability and maintainability.

The challenges do not provide complete solutions or pre-written test suites. The aim is to develop the ability to independently implement, test and debug code.

### Running Tests

Install `pytest` if necessary:

```bash
pip install pytest
```

Run your tests:

```bash
pytest -v
```

## Technical Assessment Preparation

Technical assessments evaluate more than whether a solution produces the correct output.

They also assess how well we understand problems, communicate our reasoning and approach unfamiliar requirements.

Before writing code, consider:

1. What are the inputs and expected outputs?
2. What are the requirements and constraints?
3. Which Python methods and data structures would be useful?
4. How can the problem be broken down into smaller steps?
5. What edge cases might cause the solution to fail?
6. How can the solution be tested effectively?

After completing a challenge, practise explaining how the code works, why a particular approach was chosen and what improvements could be made.

## Recommended Approach

**Understand → Plan → Implement → Test → Explain**

Work through the challenges at a manageable pace, revisiting earlier topics where necessary.

The repository will continue to grow with new coding problems covering different areas of Python, from fundamental programming concepts to more advanced problem-solving techniques.

The overall goal is to develop a strong foundation in Python, become more confident approaching unfamiliar coding problems and improve performance in technical assessments.
