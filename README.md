# Technical Assessment Practice

This repository contains Python coding challenges designed to help us prepare for technical assessments and interviews.

The aim is to strengthen our problem-solving skills, improve our understanding of Python, and build confidence in explaining our approaches to coding challenges.

The challenges are designed to be around or slightly above the difficulty of the **Mexican Wave** assessment, helping us gradually improve and become more comfortable tackling unfamiliar problems.

## Topics

The challenges focus on key Python concepts commonly used in technical assessments:

- String manipulation, indexing and slicing
- Loops and conditional statements
- Lists, tuples and dictionaries
- Sorting and searching
- Writing and running tests with `pytest`
- Handling edge cases

## Approach

Each challenge is broken down into progressive steps, starting with basic requirements and gradually introducing more complex problems.

For each challenge, we encourage everyone to:

1. **Understand the problem:** Identify the inputs, outputs and requirements before starting.
2. **Plan a solution:** Think through the logic and consider different approaches.
3. **Implement the solution:** Write Python code to solve the problem.
4. **Write your own tests:** Use `pytest` to check the solution, including edge cases.
5. **Refactor and explain:** Improve the solution where necessary and practise explaining the reasoning behind it.

The goal isn't just to complete the challenges but to understand why our solutions work and how we can improve them.

## Getting Started

Fork the repository to your own GitHub account and clone it locally.

Each challenge contains a README explaining the problem and its requirements. You'll need to create your own Python solution files and tests.

This encourages everyone to practise independently without being given the solution or test cases beforehand.

### Running the Tests

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run your tests:

```bash
pytest -v
```

## Progress

Challenges will be added regularly, with the difficulty gradually increasing as we progress.

By working through these challenges, we aim to:

- Become faster and more confident at solving coding problems.
- Strengthen our understanding of Python fundamentals.
- Improve our ability to identify and handle edge cases.
- Get better at explaining our thought processes during technical interviews.
- Learn from each other by discussing different approaches and solutions.

Everyone is welcome to contribute new challenges, share ideas and help improve the repository.

**The goal is to practise consistently, learn together and make sure we're all better prepared for our technical assessments.**
