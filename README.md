# Technical Assessment Practice

This repository contains my Python coding practice in preparation for technical assessments.

The aim is to strengthen my problem-solving skills, improve my understanding of Python, and become more confident explaining my approach to coding challenges.

## Topics

- String manipulation, indexing and slicing
- Loops and conditional statements
- Lists, tuples and dictionaries
- Sorting and searching
- Writing and running tests with `pytest`
- Handling edge cases

## Approach

Each challenge is broken down into progressive steps, starting with a basic solution and building towards more complex requirements.

For each challenge, I aim to:

1. Understand the inputs, outputs and requirements.
2. Plan my approach before coding.
3. Implement a solution in Python.
4. Write my own tests, including edge cases.
5. Refactor where needed and explain my reasoning.

## Running the Tests

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run all tests:

```bash
pytest -v
```
